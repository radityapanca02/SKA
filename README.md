<h2 align="center">Web Sekolah</h2>

🚀 **Instalasi**

<code>Terminal</code>
```bash
git clone https://github.com/radityapanca02/SKA
cd SKA

composer install && composer update
npm install && npm update

# DEVELOPMENT
cp .env.example .env

# PRODUCTION
cp .env.prod.example .env

php artisan key:generate --ansi
php artisan migrate

# OPTIMATION
composer dump-autoload -o

# RUN ON PROD
npm run build
```

---

🚂 **Run Locally**
<code>Terminal 1</code>
```bash
php artisan serve
```

<code>Terminal 2</code>
```bash
npm run dev
```
